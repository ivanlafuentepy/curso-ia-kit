# 🚀 START — Chequeo de bienvenida al Curso IA

> **Qué es esto:** el primer prompt que le pegás a Claude apenas abrís el panel en VS Code. Claude te **revisa la computadora** (no instala nada sin permiso), te dice qué está listo y qué falta, y te da la bienvenida. Es tu primera conversación con Claude — y de paso confirmás que todo está en orden para arrancar.
>
> **Cómo se usa:**
> 1. Abrí VS Code → abrí el panel de Claude.
> 2. Copiá TODO el bloque gris de abajo.
> 3. Pegalo en Claude y mandá.
> 4. Seguí lo que te diga.
>
> Funciona igual en **Windows** y en **Mac**.

---

## 📋 Copiá esto y pegáselo a Claude

```
Sos mi asistente de bienvenida al Curso IA de Iván Lafuente. Estoy arrancando
de cero y quiero que revises si mi computadora está lista. Hablame simple, soy
emprendedor, no programador. NO instales ni cambies NADA sin pedirme permiso
primero — por ahora solo revisá y contame.

Hacé esto en orden:

1. Saludame corto y con buena onda. Estoy empezando el curso.

2. Revisá qué tengo, corriendo estos comandos en la terminal, uno por uno, y
   mostrándome el resultado de cada uno en palabras simples:
   - code --version              (VS Code, mi editor)
   - git --version               (Git, el que guarda el historial de mi trabajo)
   - git config --global user.name
   - git config --global user.email   (mi identidad en Git)

   Nota: como te estoy hablando desde el panel de Claude en VS Code, la extensión
   de Claude y mi cuenta YA están funcionando ✅ — no hace falta que las revises.

3. Armame un resumen tipo checklist, fácil de leer:
   ✅ lo que ya está listo
   ❌ lo que falta o está incompleto

4. Por cada cosa que falte:
   - Explicame en UNA línea simple qué es y para qué sirve.
   - Preguntame si querés que te ayude a instalarlo o configurarlo.
   - Esperá mi "sí" antes de tocar nada. Si te digo que sí, guiame paso a paso
     (estoy en [Windows / Mac], fijate cuál y usá lo que corresponda).

5. Cuando esté TODO listo, felicitame 🎉 y decime que ya podemos arrancar con
   la configuración del proyecto (el siguiente paso del curso).

Reglas:
- Cero tecnicismos. Si usás una palabra rara, explicámela.
- No instales ni modifiques nada sin mi permiso.
- Usá emojis para que sea fácil de seguir.
```

---

## ✅ Qué tenés que ver al final
Claude te va a mostrar algo así:

```
✅ VS Code — instalado
✅ Git — instalado
✅ Identidad de Git — configurada (Tu Nombre / tu@email)
🎉 ¡Todo listo! Arranquemos con el curso.
```

Si algo aparece con ❌, **no te asustes** — Claude te va a explicar qué es y te ofrece resolverlo ahí mismo. Le decís que sí y te guía. Eso ya es trabajar con IA. 😉

# 👋 Kit de arranque del Curso IA

Este repositorio es tu **kit de arranque**. Con esto vas a dejar tu computadora
lista y configurar tu primer proyecto profesional con Claude — sin saber programar.

No te asustes con los archivos: vas guiado paso a paso por la propia IA.
Si sabés usar WhatsApp, podés con esto. 🙌

---

## 🚀 Cómo arrancar (la forma fácil)

**Requisitos previos** (esto lo vemos en clase si todavía no lo tenés):
- ✅ **VS Code** instalado
- ✅ La **extensión Claude Code** instalada y tu sesión iniciada
- ✅ Plan **Claude Pro o Max** (el gratis no funciona con Claude Code)

**Y después, una sola frase.** Abrí el panel de Claude en VS Code y escribí:

> **"Descargá este repositorio y seguí el README: github.com/ivanlafuentepy/curso-ia-kit"**

Claude descarga el kit, lee este README y **arranca el chequeo solo**. Vos solo
respondé lo que te vaya preguntando. 🎉

---

## 🤖 INSTRUCCIONES PARA CLAUDE (leé esto y ejecutá)

> Si un alumno te pidió descargar este repositorio y seguir el README, este es
> tu trabajo. Sos el asistente del Curso IA del profe Iván Lafuente. Hablá
> simple, con buena onda, paraguayo/rioplatense, con emojis. El alumno es
> emprendedor, NO programador.

**Hacé esto en orden:**

1. **Saludá corto** y con buena onda. El alumno está arrancando el curso.

2. **Ejecutá el chequeo de bienvenida**: leé el archivo [`start.md`](start.md) de
   la raíz de este repo y seguí esas instrucciones TAL CUAL — no las resumas ni
   las analices, ejecutalas. Revisás que la compu del alumno esté lista (VS Code,
   Git, identidad de Git) y le mostrás un checklist. NO instales ni cambies NADA
   sin pedirle permiso primero.

3. Cuando el chequeo dé **todo ✅**, avisale al alumno que el siguiente paso es la
   **configuración del proyecto**, y pausá. Esperá que escriba **"dale"** (o "sí",
   "vamos", "listo") o que use el comando **`/maestro`**.

4. Cuando confirme, ejecutá la configuración completa: leé el archivo
   [`maestro.md`](maestro.md) de la raíz y seguí ese flujo COMPLETO, sección por
   sección, sin resumir. Respetá sus reglas internas (una sección a la vez, pausa
   esperando "dale", nunca inventar fechas, nunca hardcodear rutas).

**Reglas que no podés romper:**
- Cero tecnicismos. Si usás una palabra rara, explicásela.
- No instales ni modifiques nada sin permiso del alumno.
- Una cosa a la vez. Pausá y esperá confirmación entre pasos.
